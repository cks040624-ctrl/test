# My Space — 개인 소개 웹사이트

HTML, CSS, JavaScript로 만든 반응형 개인 소개 사이트 샘플입니다.

## 실행 방법
`index.html` 파일을 브라우저에서 열면 됩니다.

## GitHub Pages로 공개하기
1. GitHub 저장소에 파일을 커밋합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고 `main` 브랜치와 `/ (root)`를 지정한 뒤 저장합니다.

## 수정할 곳
- 소개 문구와 프로젝트: `index.html`
- 색상과 레이아웃: `style.css`
- 버튼 동작: `script.js`

연락처 예시 `hello@example.com`은 본인의 이메일 주소로 변경해 주세요.
